# 真实模板管理纵向切片设计

日期：2026-09-17  
状态：依据已确认 PRD 和“后续采用推荐方案”授权进入实施

## 1. 目标

把当前仅在浏览器内存中演示的模板管理页面改为真实本地能力：模板规则管理可以上传 A11 派生 `.xls`、查看结构校验结果、维护草稿规则、发布版本和停用版本。所有状态写入开发用 SQLite；上传源文件复制到受管目录，原文件不修改。

## 2. 本切片边界

包含：

- `.xls` 模板上传、只读解析、SHA-256 和源文件元数据记录。
- 模板状态 `DRAFT / PUBLISHED / RETIRED`。
- 草稿规则的新增、编辑、启停和删除。
- 发布前结构阻塞项与非阻塞提醒。
- 已发布版本不可编辑；停用不删除历史。
- 同源 FastAPI API 与现有模板管理页面真实联动。
- 启动时幂等登记当前正式 A11 基线，使空数据库也能显示正式版本。

不包含：

- 动态模板参与任务创建、规则执行、完成版本和 XLS 导出；这是紧接着的下一切片。
- 登录、真实身份认证和服务端角色授权；页面角色仍明确标注为权限演示。
- 大语言模型 API、生产数据库、DOCX/XLSX 兼容声明。
- 修改上传模板内容，或自动把 A11 改写成 A12。

## 3. 数据模型

`template_versions` 保存版本级事实：ID、名称、版本、状态、源文件名、受管副本路径、SHA-256、源行数、执行项数、校验结果、创建人、创建/更新时间和发布时间。`(name, version)` 唯一。

`template_rules` 保存版本内规则快照：规则 ID、来源行、来源序号、名称、可验证要求、所需材料、主判定方式、确认边界、是否启用和更新时间。`(template_id, rule_id)` 唯一。

已发布版本的记录和规则不可修改。停用只改变版本状态，不删除记录、规则或源文件。

## 4. 模板结构校验

上传阶段只读打开 `.xls`，至少验证：

1. 文件可由 `xlrd` 打开。
2. 存在且仅存在一个 `硬件测试过程检查表` 工作表。
3. `A2` 存在版本值，且 `A111` 被明确拒绝为历史笔误。
4. 工作表至少包含 D/E/F/G 四个结果列。
5. A11 派生结构的 22 个来源行均存在，来源序号可唯一对应；TR-05 保留但默认不执行。

结构缺失产生阻塞项，模板仍可保存为草稿但不可发布。缺少自动判定条件、证据定义或语义标准产生非阻塞提醒；管理员可以发布，后续审核执行必须把无法形成明确证据的项送入待人工确认。

## 5. API

- `GET /api/templates`：列出所有模板版本。
- `POST /api/templates`：上传 `.xls` 并创建草稿。
- `GET /api/templates/{template_id}`：返回版本、规则和校验结果。
- `PUT /api/templates/{template_id}/rules/{rule_id}`：更新草稿规则。
- `POST /api/templates/{template_id}/rules`：新增草稿规则。
- `DELETE /api/templates/{template_id}/rules/{rule_id}`：删除草稿规则。
- `POST /api/templates/{template_id}/publish`：无阻塞项时发布。
- `POST /api/templates/{template_id}/retire`：停用已发布版本。

错误继续使用项目现有 `{error:{code,message,details}}` 结构。上传文件不可读、版本重复、已发布版本修改、发布受阻和对象不存在均返回稳定错误码。

## 6. 前端行为

真实模式进入模板管理时从 API 加载数据，不再显示“模板管理模拟”。上传表单显示选中文件并提交。列表展示版本、状态、22 个来源行/执行项数量、创建人和更新时间。

编辑页对已发布/停用版本只读；草稿可编辑字段、启停、新增、删除和发布。阻塞项使用错误样式，提醒项使用警告样式。所有请求失败显示稳定错误码和中文消息。

`?mode=demo` 继续保留固定演示数据，便于无数据库演示。

## 7. 安全与一致性

- 上传只接受 `.xls`，文件名经过安全化处理。
- 先计算内容哈希，再复制到 `storage/templates/<uuid>/source.xls`；不覆盖同名源文件。
- 校验和规则维护均不写入工作簿。
- 数据库写入失败时清理尚未登记的受管副本。
- 发布操作在一个事务中再次读取当前校验结果并检查阻塞项。
- A11 基线登记是幂等操作，不覆盖已有版本。

## 8. 验收

- 合法 A11 源文件上传后形成草稿，显示 22 个来源行、21 个执行项和可追溯哈希。
- 缺少工作表、版本为 A111 或来源行不完整时形成阻塞项且发布返回 `TEMPLATE_PUBLISH_BLOCKED`。
- 草稿规则可新增、修改、启停和删除；已发布版本同样操作返回 `TEMPLATE_IMMUTABLE`。
- 发布后刷新页面、重启应用仍能读取；停用后历史仍存在。
- 原上传文件 SHA-256、大小和修改时间不变。
- 后端全量、前端全量以及 SQLite 重启恢复测试全部通过。
